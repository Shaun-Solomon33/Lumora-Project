# Lumora

Lumora is a mobile-first emergency response and disaster management application built for rapid crisis awareness, coordination, and citizen support.

It provides a dual-interface experience:
- Resident Portal for live risk monitoring, SOS support, survival guidance, and AI-powered assistance
- Command Center for handling incoming SOS alerts, coordinating volunteers, and issuing public broadcasts

## Core Features

- Real-time hazard dashboard with weather, rainfall, wind, pressure, and seismic indicators
- Live alert feed using public emergency and disaster data sources
- SOS reporting workflow for emergency situations
- AI Guide for disaster preparedness and support
- Survival Vault for offline-friendly emergency guidance
- Volunteer and operations view for response coordination
- Broadcast system for command-side alerts and announcements
- Location-aware experience with geolocation support

## Tech Stack

- React
- TypeScript
- Vite
- Capacitor
- Firebase
- Gemini API integration

## Run Locally

Prerequisites:
- Node.js

Steps:
1. Install dependencies with `npm install`
2. Configure the required environment variables in `.env`
3. Start the development server with `npm run dev`

## Build

- Web build: `npm run build`
- Type check: `npm run lint`

## Project Purpose

Lumora was developed as a disaster management and emergency response application focused on improving preparedness, communication, and rapid assistance during critical situations.
